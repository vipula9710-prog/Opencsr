# Changelog

All notable changes are documented here. The project follows [Semantic Versioning](https://semver.org/).

## [0.1.0] — Initial release

### Added
- Multi-organisation CSR platform: setup wizard, organisation switcher, platform administration, custom domains.
- Authentication with database sessions, rate limiting and password reset; nine roles with granular permissions; audit log.
- CSR programmes, configurable focus areas and projects with milestones, tasks, evidence, images and history.
- NGO/partner CRM with configurable due diligence and verification workflow.
- Budget plans, allocations, expenditure and disbursements with decimal-safe arithmetic.
- Impact indicators and measurements with independent verification.
- Approvals, notifications, documents with versions, generated reports with PDF export.
- Blog CMS with scheduling, RSS and SEO; media library; contact form and enquiry management.
- Visual website builder with themes, typography, components, 16 section types, templates, responsive preview, drafts, publishing, revisions and rollback.
- Fictional GreenFuture Foundation demo seed and removal script.
- Docker, Docker Compose, Railway configuration, CI workflow, unit/integration/E2E tests and documentation.
